核心特性与技术亮点

深度挖掘现代电台潜能，重塑 Android 平台上的 APRS 通联体验

📻

Icom WLAN 直连与硬件联动

支持 IC-705、IC-9700、IC-7610、IC-905 及自定义 CI-V 地址。通过 Wi-Fi 直连实现 AX.25 AFSK1200 12kHz 音频收发与 CI-V PTT 控制。自动同步电台工作频率，支持优先使用电台机载 GPS 经纬度/航向/速度发射信标。

🔌

400+ 款 USB 电台支持 (Hamlib)

集成 Hamlib 4.7.2 原生核心，内置免 root 本地 Android USB CAT 环回桥与专用声卡输入/输出路由。精确依据音频采样率推算物理排空时序，彻底解决 PTT 释放挂起与长发空载波。

🛰️

现代 APRS 协议全规格实现

APRS 1.2 DAO 亚米级定位（网格分辨率达 ~11cm）；APRS 101 第 9/10 章 PHG 功率/高度/增益/指向性设置与直频覆盖半径推算；第 12 章 WX 气象站解析；第 15 章 Queries（?PING? / ?APRST / ?VER?）自动应答。

🀄

智能自适应编码 (告别乱码)

内置针对中国及亚太地区的双向评分探测模型，自适应解析 GB2312 / GBK / GB18030 与 UTF-8 字符集。独创 Latin-1 错误转码逆向还原修复算法，国内台站备注与天气播报零乱码。

🗺️

双地图引擎与离线区域管理

基于 MapLibre Native 提供高德地图、OpenStreetMap 及自定义栅格瓦片离线区域下载与缓存；内置 Google Maps SDK 支持谷歌普通与卫星底图。

100% 纯 Kotlin 现代架构与 Jetpack Compose + Material 3 统一底栏导航；本地 PCM AFSK1200 解调由 Graywolf 原生引擎支撑；R8 与原生编译深度裁减，安装包由近 100 MB 瘦身至 ~44 MB。

电台连接配置指南

简单几步，打通无线电台与 Android 手机的双向数据链路

IC-705 / IC-9700 WLAN 直连说明

  1. 电台端开启 WLAN：以 IC-705 为例，进入 MENU → SET → WLAN & Internet → WLAN 开启无线局域网。
  2. 配置网络与用户：使用 Access Point 热点模式，或让手机与电台连入同一 Wi-Fi。在 Network User / Pass 中创建用户名和密码（最长 16 个 ASCII 字符），确认控制端口（默认 50001）。
  3. 手机连接热点：手机连入电台 Wi-Fi；Android 提示“此网络无互联网连接”时选择保持连接。蜂窝移动数据仍可正常访问公网。
  4. APRSdroid Mod 设置：
    • 连接协议选择 IC-705 Wi-Fi；
    • 选择预置型号 IC-705（自动填充默认 CI-V 地址 A4）；
    • 填入电台 IP、端口及 Network 账号密码；
    • 可在下方勾选“自动同步电台工作频率”与“优先使用电台 GPS 坐标”；
    • 可先进入设置中的“IC-705 诊断”界面，验证 CI-V 与音频通信握手。

USB 电台 (Hamlib 4.7.2) 配置说明

  1. 连接电台：手机通过 USB OTG 数据线连接电台自带 USB 接口（如 IC-705、IC-7300、FT-891、FT-991A 等内置声卡和 CAT 串口的机型）。
  2. APRSdroid Mod 设置：
    • 连接协议选择 USB 电台 (Hamlib)；
    • 点击“电台型号”，在弹出列表中按品牌拼音快速检索您的机型；
    • 系统将根据型号自动填充波特率与默认 CI-V 地址；
    • 在“音频输入设备”与“音频输出设备”中选择识别到的 USB 声卡（如 USB Audio Device）；
    • 微调“发射音量”滑块，防止过调制失真；发射时系统将依据采样率精确推算物理排空延时，保障 PTT 释放安全。

APRS-IS 互联网模式与传统 TNC

  1. APRS-IS 互联网：连接协议选择 APRS-IS，填写呼号、验证码（Passcode）及服务器地址（如 china.aprs2.net:14580）。
  2. 传统 TNC 与蓝牙：全面保留 APRSdroid 经典的蓝牙 TNC、音频麦克风 AFSK（由 Graywolf 引擎解调）、KISS、TNC2、Kenwood 协议支持。

常见问题 (FAQ)

使用与配置过程中的高频疑问解答

手机连上 IC-705 Wi-Fi 后，微信/网页无法上网怎么办？

APRSdroid Mod 已经实现了严格的网络隔离：电台数据流仅绑定选定的 Wi-Fi Network Socket，不会把整机全局默认路由绑定到电台。只要您在手机设置中保持蜂窝移动数据开启，手机即可一边直连电台收发 APRS，一边通过 4G/5G 正常上网。

为什么之前版本 PTT 释放偶发卡死或空载波长发？

在 Mod-v2.4.0+ 及后续版本中，已引入基于采样率和声卡缓冲长度的精准声卡物理排空时序计算模型，在音频完全输出后才释放 PTT，并配合双向 ACK 和后台 Watchdog 超时熔断保护，已彻底解决该偶发问题。

国内台站中文备注乱码问题是如何解决的？

本项目实现了解码前自适应编码探测器（GB2312 / GBK / GB18030 / UTF-8）与针对已错误解码 Latin-1 字节流的逆向还原修复算法，无论报文来自无线电直频还是 APRS-IS 网关，均可自动还原为正确的中文内容。

我应该下载哪个 APK 安装包？

绝大多数近 6~7 年生产的 Android 手机都是 64 位 ARM 架构，请首选 ARM64-v8a OpenGL 安装包；如果您使用的是车载中控屏、旧款机顶盒或老款手机，请选择 ARMv7。
